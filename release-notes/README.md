\# LedgerOne Desktop – Release Notes



This directory contains version-specific release documentation for LedgerOne Desktop.



\## Naming Convention



Create one Markdown file for each application release.



Examples:

\- v1.0.0.md

\- v1.0.1.md

\- v1.1.0.md



\## Required Information



Every release note should contain:



1\. Version number.

2\. Release date.

3\. New features.

4\. Improvements.

5\. Bug fixes.

6\. Security changes.

7\. Minimum supported Windows version.

8\. Known issues.

9\. Installer filename.

10\. SHA-256 checksum.



\## Important



Release notes must accurately describe the features and fixes included in the corresponding installer.



Do not publish unverified features or security claims.
